# 🚗 Car Price Prediction

A **Machine Learning project** that focuses on predicting car prices based on different vehicle characteristics and historical data.

The project follows a complete machine learning workflow, starting from **data exploration and preprocessing** through **exploratory data analysis, feature engineering, model training, and evaluation**.

### 🔍 Key Features

* 📊 Exploratory Data Analysis (EDA) to understand the dataset and identify important patterns
* 🧹 Data cleaning and preprocessing
* 🔄 Encoding and transformation of categorical features
* 📈 Analysis of relationships between car features and prices
* 🤖 Training Machine Learning regression models
* 📏 Model evaluation using appropriate regression metrics
* 💰 Prediction of car prices based on vehicle characteristics
* 📊 Data visualization to communicate findings and model performance

### 🛠️ Tools & Technologies

* **Python**
* **Pandas** – Data manipulation and preprocessing
* **NumPy** – Numerical computing
* **Matplotlib** – Data visualization
* **Seaborn** – Statistical visualization
* **Scikit-learn** – Machine Learning and model evaluation
* **Jupyter Notebook** – Development and analysis environment

### 🎯 Objective

The main objective of this project is to build a Machine Learning model capable of estimating car prices from historical data and identifying the vehicle characteristics that have the greatest influence on price.

This project demonstrates practical skills in **Machine Learning, Regression, Data Preprocessing, Exploratory Data Analysis, Feature Engineering, and Data Visualization**.

### 📌 Machine Learning Approach

The project treats car price prediction as a **regression problem**, where the model learns the relationship between vehicle features and the target price and then uses those relationships to generate predictions for new data.

### 💡 Project Outcome

The analysis provides insights into the factors affecting car prices while demonstrating how historical automotive data can be transformed into a predictive Machine Learning solution.
